- # 120 Years of Olympic History: Data Cleaning & EDA 🏅📊

## 📌 Project Overview
This project performs a comprehensive Exploratory Data Analysis (EDA) on a historical dataset covering 120 years of Olympic Games. The goal is to uncover long-term trends in athlete performances, demographics, and medal distributions across different nations and eras.

## 📊 Dataset Source
Due to file size limitations, the main dataset is not fully hosted here. You can download the source data directly from:
- [Kaggle Dataset Link](https://www.kaggle.com/code/faridghattas/da-olympic-history-for-athletes-and-results/input)
 
## 🛠️ Tech Stack & Libraries
- **Language:** Python
- **Environment:** Jupyter Notebook
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn

## 🔍 Key Insights & Findings
- **Gender Diversity:** Documented the historical growth and trajectory of female athlete participation over the decades.
- **Dominance Trends:** Identified top-performing countries and mapped medal distributions across changing geopolitical eras.
- **Physical Attributes:** Analyzed correlations between athletes' height, weight, and specific sports categories.

## 📈 Data Pipeline & Techniques
1. **Data Cleaning:** Handled missing values spanning over a century, deduplicated records, and standardized country names.
2. **Exploratory Data Analysis (EDA):** Applied descriptive and inferential statistical methods to discover hidden patterns.
3. **Advanced Visualization:** Built informative trend lines, bar charts, and heatmaps using Seaborn to present complex data clearly.

---
*💡 **Domain Transferability:** The trend analysis frameworks and large-scale data cleaning techniques utilized in this project are highly applicable to analyzing long-term vehicle depreciation, fleet performance history, and market pricing in the Automotive Sector.*
